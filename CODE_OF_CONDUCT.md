# Código de Conduta

## Nosso Compromisso

O Diamond Forge é um espaço de aprendizado intenso e respeito mútuo. Como participante, você se compromete a:

- **Respeitar** todos os colaboradores, independentemente de experiência, formação ou opinião.
- **Criticar ideias, não pessoas.** Críticas construtivas são bem-vindas; ataques pessoais não.
- **Incentivar perguntas.** Ninguém nasce sabendo metaclasses.

## Padrões

Exemplos de comportamento que contribuem para um ambiente positivo:

- Usar linguagem acolhedora e inclusiva.
- Focar no que é melhor para o aprendizado coletivo.
- Aceitar feedback construtivo com humildade.

## Padrões Inaceitáveis

- Assédio, discriminação ou linguagem ofensiva.
- Spam, trollagem ou desvio do propósito.
- Publicação de informações pessoais sem consentimento.

## Escopo

Aplica-se a todos os espaços do projeto (issues, pull requests, discussões e código).
